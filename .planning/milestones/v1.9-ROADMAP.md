## v1.9 Theme

Track tables become a first-class spatial mode. The map-layer form auto-suggests Track when a table has the TRACKID + x + y + ordering column shape, narrows render modes to Raster + Class Break (heatmap excluded for tracks), surfaces a full TRACK STYLE param surface with alpha-aware color pickers, and round-trips track styling through save/reload. The work is verified end-to-end via a live operator walk-through against the deployed Kinetica instance.

DOUBLE-precision x/y visibility), and the WMS builder + info-query path translate track columns onto the existing latlon spatial-attr wire (X_ATTR/Y_ATTR from track_config.xCol/yCol).

**Depends on**: Phase 52
**Requirements**: RENDER-V19-01, RENDER-V19-02, RENDER-V19-03, COLOR-V19-01
