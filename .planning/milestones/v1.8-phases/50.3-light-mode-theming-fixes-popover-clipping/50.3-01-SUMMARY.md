## Task 2: Popover Clip Fix (Bug 2) + Role-Chip Light Override (Bug 3) + Topbar/Profile Sweep

### (A) Popover clip fix — global.css .users-table-wrap

Changed `overflow-x: auto` to `overflow: visible`. The 5-column Users table (checkbox | username | roles | last-seen | actions) does not need horizontal scroll at normal viewport widths. This removes the clip context so the absolutely-positioned `.users-popover` (which opens `top: calc(100% + 4px); right: 0`) is fully visible on every row including the last.

**Option chosen:** (a) overflow: visible — CSS-only, no markup changes, `.users-popover` class preserved for specs.

### (B) Light-mode role-chip override — global.css

Added immediately after the closing brace of the base `.role-chip` block:

```css
:root[data-theme="light"] .role-chip {
  color: #15803d;
  background: rgba(34, 197, 94, 0.14);
  border-color: rgba(21, 128, 61, 0.35);
}
```

Base `.role-chip` (dark: `#86efac` on translucent green) and `.role-chip--default` (token-based: `--chip-bg`/`--border`/`--muted`) left unchanged.
