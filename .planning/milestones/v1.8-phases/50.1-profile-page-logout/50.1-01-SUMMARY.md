## Decisions Made

- groupPermissionList() takes an arbitrary list rather than the full catalog, so ProfilePage can show only the current user's effective permissions (not the entire catalog matrix)
- Log out calls `useAuthStore.getState().logout()` — the store's logout() calls apiLogout() then sets status to "unauthenticated", which fires App.tsx's existing canonical 6-store reset effect. No reset logic duplicated in Topbar
- ProfilePage is not added to Sidebar navigation — it is a Topbar-only page
- "profile" added to the ReturnTo allowlist to cover OIDC re-auth during Profile page visit
- 51-02-PLAN.md patched on disk without a commit (it lives in .planning/ which is gitignored)
