### 🚧 v1.3 Unified Dashboard Filtering (In Progress)

**Milestone Goal:** Replace v1.2's broken WMS-QUERY filter and client-side WHERE-injection path with a single server-side primitive — a transient Kinetica materialized view per (user, session, dashboard, table) — that every chart, records-table, and map widget queries when filters are active. Closes TD-V12-01 and TD-V12-04.

- [x] **Phase 13: spikes-and-endpoint** — Operator spike validation + net-new materialize endpoint (completed 2026-05-06)
- [x] **Phase 14: filter-view-store** — `useFilterViewStore` Zustand slice + client API helpers (completed 2026-05-06)
- [x] **Phase 15: chart-filtering** — FROM-swap in all chart renderers + dead-code deletion + lifecycle reset wiring (completed 2026-05-07)
- [x] **Phase 16: map-filtering** — LAYERS-swap in map renderer + wmsUrlBuilder cleanup (completed 2026-05-07)
- [x] **Phase 17: verification** — Test fixture + end-to-end verification (closes TD-V12-01 + TD-V12-04) (completed 2026-05-07)
