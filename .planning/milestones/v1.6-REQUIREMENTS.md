# Requirements — v1.6 Dynamic Views

**Milestone:** v1.6 Dynamic Views
**Goal:** Operators define dashboard-scoped saved SQL templates that re-materialize on top of the filter view, guarded by a max-records threshold. Visualizations bind to a dynamic view as their data source; over-threshold dependents render an empty state.

**Status legend:** `[ ]` open · `[~]` in progress · `[x]` done · `[!]` dropped

## Foundation (Phase 32)

- [x] **DV-V16-01** — SQLite table `dashboard_dynamic_views` (`id`, `dashboard_id`, `source_table_id`, `name`, `template_sql`, `max_records`, `columns_json`, `created_at`, `updated_at`) with idempotent migration (mirrors v1.4 Phase 19 pattern).
- [x] **DV-V16-02** — Pure helper `substituteViewToken(template, viewName)` replaces `{view}` token (case-insensitive, whitespace-tolerant) and throws on absent token.
- [x] **DV-V16-03** — `POST /api/dynamic-view/preview` runs a one-shot `SELECT * FROM (<substituted_sql>) LIMIT N` against Kinetica and returns `{ rows, columns }`. No permanent view created.
- [x] **DV-V16-04** — `POST /api/dynamic-view/materialize` row-count gates against `max_records`: below → `CREATE OR REPLACE MATERIALIZED VIEW <dynamic_view_name>` (TTL=5); at/above → `DROP TABLE IF EXISTS <dynamic_view_name>` and return `{ status: "over_threshold" }`. TM/SMc:1078 race-recovery retry preserved.
- [x] **DV-V16-05** — `DELETE /api/dynamic-view/:id` drops the materialized view + row. Supertest coverage in both `AUTH_MODE=password` and `AUTH_MODE=oidc` for preview, materialize-below, materialize-over, unsubstituted-token (400), error propagation.

## Locked Decisions

- **Template token**: `{view}` — single substitution point, case-insensitive, whitespace-tolerant.
- **No-filter behavior**: treat as over-threshold → dynamic view dropped, dependents show empty state. The threshold gate is the safety story; running unfiltered would defeat it.
- **Columns persistence**: persist `columns_json` in DB on Save (refreshed when SQL changes) so ChartConfigPanel pickers don't need round-trips.
- **Scoping**: dashboard-scoped (NOT global); multiple dynamic views per dashboard; lifecycle reset on logout / dashboard switch.
