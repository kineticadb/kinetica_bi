# Requirements: Kinetica BI — Milestone v1.7 WMS Class Break, Track & Legend

**Defined:** 2026-05-18
**Core Value:** Click-through data exploration — users drill into chart elements and the entire dashboard filters to that slice of data, enabling fast iterative analysis without writing SQL.

**Milestone Goal:** Expand the LayersModal beyond raster + heatmap to the full Kinetica WMS render-style surface (classbreak with full CB_* params + categorical breaks + Quantile auto-suggest + per-break labels; track styling as a sub-mode under raster AND classbreak gated on a track-table column shape) and ship a reusable Map Layers Panel + Legend component shipped as both a floating overlay on each map widget and a standalone "Legend" dashboard widget.

**Carry-in (deferred to v1.8+):** TD-V16-TEST-ISOLATION, TD-V14-WKB-SPIKE, TD-V15-MAP-ONLY-TRIGGER, TD-V15-LIVE-UAT (v1.5+v1.6 portions), TD-V11-04, TD-V13-01.
