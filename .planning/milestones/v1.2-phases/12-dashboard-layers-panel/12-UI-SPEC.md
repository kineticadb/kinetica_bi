| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f172a` (`--bg`) | Page background, deep input backgrounds (`#0b1224`) |

- The "+ Add layer" button (`.btn-primary`)

**Accent-2 `#38bdf8` (`--accent-2`):** Reserved for the "Reconfigure" placeholder badge border/text on old-config map widgets (semantic: informational/warning, distinct from destructive red). Mirrors `.login-banner` treatment.

- Card/panel surface: `rgba(255, 255, 255, 0.04)` (`--card`) — layer list row backgrounds, right-pane form background
- Deep input surface: `#0b1224` — all text inputs, selects, textareas within `KineticaWmsLayerForm`
- Border: `#1f2937` (`--border`) — all container borders

**Error badge (missing table):**
- Background: `rgba(239, 68, 68, 0.12)` (matches `.login-error` pattern)
- Border: `rgba(239, 68, 68, 0.4)`
- Text: `#fecaca`

## Interaction Contract

### LayersModal

| Interaction | Behavior |
|-------------|----------|
| Open | "Layers" button click → `setShowLayersModal(true)` → modal mounts; if no layers exist, auto-creates a blank layer and selects it |
| Close | X button click, ESC key, or overlay click → `setShowLayersModal(false)` → pending debounced PATCH fires immediately before unmount |
| Layer select | Click anywhere on `.layer-row` → right pane loads that layer's `KineticaWmsLayerForm` |
| Add layer | "+ Add layer" button → POST new blank layer → optimistic store update → layer selected in right pane |
| Delete layer | Trash icon → inline confirm prompt (see Copywriting) → DELETE request → layer removed from list; if deleted layer was selected, right pane shows `.layers-modal-empty` |
| Duplicate layer | Duplicate icon → POST clone → appended to list with `position = max + 1` → new layer selected in right pane |
| Visibility toggle | Eye icon → toggle `layer.config.visible` (boolean) → optimistic store update + debounced PATCH; map widgets skip rendering invisible layers |
| Drag reorder | `draggable` attribute + `onDragStart`/`onDrop`/`onDragOver` native events; on drop → `PATCH /api/dashboards/:id/layers/reorder` with normalized `orderedIds[]`; store updated optimistically |
| Field edit | Any `KineticaWmsLayerForm` field change → optimistic store update → debounced PATCH (300ms). No Apply/Cancel buttons. |

### KineticaWmsLayerForm

| Interaction | Behavior |
|-------------|----------|
| Table select | Dropdown change → `autoSuggestSpatialMode` runs → `spatialMode` updated + stale column fields cleared; form patches via `onChange(patch)` |
| Spatial mode change | Radio group change → column dropdowns repopulate from `getValidSpatialColumns`; prior column values cleared |
| Render mode change | Radio group change → render-mode param groups show/hide (raster: pointColor/pointSize/pointOpacity; heatmap: colormap/blurRadius; classbreak: cbColumn/cbBreakType/classbreaks builder; contour: contourColor/smooth/bandwidth) |
| Classbreak column pick | Dropdown select → `probeCardinality` fires; if >100 show `.config-cardinality-warn`; if >256 show `.config-cardinality-cap` + disable Apply |
| Opacity slider | Range input change → optimistic `dashboardLayersStore.updateLayer(id, { config: { POINTOPACITY: val } })` + `imageLayer.setOpacity(val / 100)` + debounced PATCH |
| Table removed badge | Auto-shown when layer's `table_id` not in `associatedTables`; edit icon selects layer in right pane for reconfiguration |

### MapChartRenderer (updated behavior)

| Interaction | Behavior |
|-------------|----------|
| Layer list change | `map.addLayer()` / `map.removeLayer()` on the existing map instance — never dispose/recreate (M-01 lock) |
| Filter change (per layer) | `imageWmsSource.updateParams({ QUERY: whereClause, _v: String(filterVersion) })` per layer (M-02 lock); only the layer whose `tableId` matches the changed filter updates its QUERY value |
| Visibility toggle | Invisible layers skip `map.addLayer()` or call `imageLayer.setVisible(false)` — no tile requests fired |
| Old-config detection | `config.spatialMode !== undefined && config.includedLayerIds === undefined` → render `.widget-map-reconfigure` overlay instead of OL map |

## State Coverage

All states that must be rendered for Phase 12 UI surfaces:

### LayersModal states

| State | Trigger | Visual |
|-------|---------|--------|
| No layers (first open) | Dashboard has zero layers | Auto-create blank layer; right pane shows form immediately — no empty-state screen |
| Layer list with layers | Dashboard has 1+ layers | Left rail shows list; first layer selected by default |
| Layer selected | User clicks row or new layer created | Row has `.active` class; right pane shows `KineticaWmsLayerForm` |
| No layer selected | Deleted last layer | Right pane shows `.layers-modal-empty` |
| Layer dragging | `onDragStart` fired | Dragged row has `opacity: 0.5` (inline style via JS) |
| Layer saving | Debounce in flight | No visual indicator required (auto-save is immediate optimistic update; PATCH is background) |
| Layer save error | PATCH rejects | Toast: "Failed to save layer — check your connection" |

### Layer row states

| State | Visual |
|-------|--------|
| Default | `.layer-row` — transparent border |
| Hover | `.layer-row:hover` — `rgba(255,255,255,0.03)` background |
| Selected | `.layer-row.active` — `var(--card)` background |
| Visibility hidden | `.layer-row-eye.hidden` — eye icon at 0.3 opacity |
| Missing table | `.layer-row-badge.error` inline badge; row still selectable for reconfiguration |
| Delete confirm | Inline `.confirm-actions` replaces trash icon (matches existing DashboardsPage pattern); labels: `[Delete layer]` and `[Keep layer]` |

### KineticaWmsLayerForm states

| State | Visual |
|-------|--------|
| Incomplete (no table selected) | Table dropdown shows placeholder; spatial/render fields disabled with `opacity: 0.5` |
| Valid | All required fields filled; no error states |
| Cardinality warning | `.config-cardinality-warn` text below break column dropdown |
| Cardinality error | `.config-cardinality-cap` text; duplicate row addition disabled |
| Auto-suggest active | `__autoSuggestActive` hint text via `.config-hint` |

### Map widget states

| State | Visual |
|-------|--------|
| No layers included | `.widget-map-empty` overlay: "No layers — open the Layers panel to add some" |
| Old config (Phase 11 widget) | `.widget-map-reconfigure` overlay with `.widget-map-reconfigure-badge` |
| Layer loading tiles | OL default loading (no spinner overlay — existing Phase 11 pattern) |
| Layer tile error | `.widget-map-error` overlay (existing Phase 11 class) |
