## Remediation (2026-09-30, operator chose option B)

**F1 — fixed.** `SchemaSyncModal` takes `onApplied(columns)`, called only on an `applied`
outcome with the map the server stored. `TableDetail` re-reads the row with `getTableById`
(`updated_at` moved too) and falls back to patching in the returned columns if that fails;
`DatasetsPage` replaces both `view.table` and the `tables` list entry. Tests: `ONAPPLIED-applied`,
`ONAPPLIED-not-on-no-changes`, `ONAPPLIED-not-on-stale` (SchemaSyncModal.spec) and
`REFRESH-after-apply`, `REFRESH-fallback`, `REFRESH-list-count` (DatasetsPage.schemasync.spec),
negative cases each with a render-reached proof. Probes: 4/4 fired, each on its own test
(modal never calls back → ONAPPLIED-applied; parent ignores it → all three REFRESH; list not
patched → REFRESH-list-count only; fallback dropped → REFRESH-fallback only). The first P3 run
was a NON-RESULT — its anchor matched twice (edit mode carries the same `setTables` line), the
mutation never landed, and it was re-run on the view-mode line alone. Not re-verified live.

**F2 — fixed, and wider than reported.** The checker flagged only `WEB_EXCLUDED_DRILLDOWN_TYPES`;
the three "guarded" mirrors in `lib.columnTypeClass.spec.ts` (`NUMERIC_TYPES`, `BOOLEAN_TYPES`,
`DATETIME_TYPES`) had the same defect — hardcoded on the web side, so they reddened on a server
edit but never a web one. New `tests/helpers/webColumnTypes.ts` `readWebTypeSet(name)` parses the
Set literal out of `packages/web/src/lib/columnTypes.ts`, throwing (never returning `[]`) when a
declaration is missing or empty. All four MIRROR-PARITY tests now compare against it. Probes on
the WEB file: +1 excluded type, +1 numeric type, −1 datetime type, and a Set rename — each
reddened its parity test (4/4). Control: the PRE-fix spec, run against the +1-excluded-type
mutation, passed 23/23 — the old guard demonstrably could not fail. The Phase 125 roadmap line
saying this mirror "was closed and probed in cc30404" was therefore inaccurate; the test added
there compared a literal to a literal.

**PG-3 — fixed.** `REQUIREMENTS.md` rollup → `Complete: 19`.

**Gates after remediation:** web tsc clean; vitest 185 files / 4162 tests; theme-guard 154;
server tsc clean; server `test-gate.mjs` GATE PASSED — 1490/1543, 8 failing files, all 8 in the
