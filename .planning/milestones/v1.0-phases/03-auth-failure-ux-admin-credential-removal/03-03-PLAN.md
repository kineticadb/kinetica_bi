<objective>
Wire the frontend to dispatch on the response `code` field instead of the bare HTTP status. apiFetch peeks the response body on 401 and only fires UNAUTHORIZED_EVENT when `code === "REAUTH_REQUIRED"`. New client-side error classes (PermissionError, ReauthRequiredError, UpstreamError) replace generic Error throws so callers can `instanceof`-switch instead of parsing strings. useAuthStore tracks WHY the user was logged out (`reason: "session-expired" | null`) so LoginPage (Plan 03-04) can show the right banner.

Purpose: UX-01 requires the "your session has ended" banner to appear ONLY when the user was logged out by mid-session auth failure (not on first-load bootstrap or explicit logout). UX-03 requires the frontend dispatch on `code`, not just status, so future endpoints returning 401 for non-session reasons don't accidentally log the user out.

Output: Frontend network plumbing handles the new contract. Existing widgets keep working (their try/catch still fires; they now receive instanceof-checkable errors instead of generic Errors). LoginPage banner and useApiQuery hook arrive in Plan 03-04 — this plan ships the wire.
</objective>

       ```typescript
         if (response.status === 401 && typeof window !== "undefined") {
           // Body-peek for code: "REAUTH_REQUIRED". Clone so the original response stream
           // remains consumable by the caller. Failure to parse → fall back to no-dispatch
           // (defensive — future 401 reasons should NOT logout the user unless the server
           // explicitly says REAUTH_REQUIRED).
           let shouldDispatch = false;
           try {
             const peek = await response.clone().json();
             if (peek && typeof peek === "object" && (peek as { code?: string }).code === "REAUTH_REQUIRED") {
               shouldDispatch = true;
             }
           } catch {
             // body wasn't JSON or already consumed — do not dispatch
           }
           if (shouldDispatch) {
             window.dispatchEvent(new CustomEvent(UNAUTHORIZED_EVENT));
           }
         }
         return response;
       };
       ```

       ```typescript
       const throwForStatus = async (response: Response, fallbackMessage: string): Promise<never> => {
         // Try to read { error: string } from JSON body; fall back to text or status code.
         let message = fallbackMessage;
         try {
           const body = await response.clone().json();
           if (body && typeof body === "object" && typeof (body as { error?: unknown }).error === "string") {
             message = (body as { error: string }).error;
           }
         } catch {
           const text = await response.text().catch(() => "");
           if (text) message = `${fallbackMessage}: ${text}`;
         }
         if (response.status === 401) throw new ReauthRequiredError(message);
         if (response.status === 403) throw new PermissionError(message);
         if (response.status === 502) throw new UpstreamError(message);
         throw new Error(`${fallbackMessage}: ${response.status}`);
       };
       ```
