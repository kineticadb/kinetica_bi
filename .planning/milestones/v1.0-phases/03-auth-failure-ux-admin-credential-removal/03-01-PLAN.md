<objective>
Mount the global Express error-handling middleware that translates Phase 2's typed Kinetica errors into the user-visible HTTP responses Phase 3 promises. This wave ADDS the middleware and its tests; routes still have their Phase-2 try/catches intact (those are stripped in Plan 03-02). Output: A mounted error-handling middleware in kinetica_bi/server/src/index.ts and a dedicated spec file (`tests/errorMiddleware.spec.ts`) proving the four translation rules end-to-end via supertest.
