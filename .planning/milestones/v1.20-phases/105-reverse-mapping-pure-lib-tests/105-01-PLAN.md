    ```typescript
    export function computeReverseFilterMap(args: {
      filters: Record<number, ActiveFilter[]>;
      dvFilters: Record<number, ActiveFilter[]>;
      shapes: Shape[];
      vizs: VizDescriptor[];
      dvFilterScopeDisabled: boolean;
    }): { filterEntries: FilterApplyEntry[]; shapeEntries: ShapeApplyEntry[] }
    ```

    Algorithm (do not deviate):
    1. Seed one `Map<ActiveFilter, WidgetApplyEntry[]>` entry (empty array) for every filter in every `filters[*]` and `dvFilters[*]` list; seed one `Map<Shape, WidgetApplyEntry[]>` entry for every shape. This guarantees the LOCKED zero-match => empty-widgets contract.
    2. Sort a COPY of vizs by widgetId ascending (`[...args.vizs].sort((a,b)=>a.widgetId-b.widgetId)`) for deterministic output; iterate the copy (never mutate `args.vizs`).
    3. Per viz: `isDv = viz.dynamicViewId !== undefined`; `effectiveCfg = isDv && args.dvFilterScopeDisabled ? undefined : viz.cfg`; `effectiveSpatialCapable = isDv ? false : viz.spatialCapable`; `activeList = isDv ? (args.dvFilters[viz.dynamicViewId!] ?? []) : (viz.tableId !== undefined ? args.filters[viz.tableId] ?? [] : [])`.
    4. `resolveFilterSet(effectiveCfg, activeList)` → for each returned filter, look it up in the seeded Map (guaranteed present by identity) and add a widget match.
    5. If `effectiveSpatialCapable`, `resolveSpatialShapes(effectiveCfg, args.shapes)` → for each returned shape, add a widget match to the shape entry.
    6. Widget match helper: dedup by `widgetId` (Array.find); create `{ widgetId, widgetTitle, layerNames: undefined }` on first match; when `viz.vizKind === "layer" && viz.layerName`, append the name to `layerNames`.
    7. Return `{ filterEntries, shapeEntries }` as arrays: `[...map].map(([filter, widgets]) => ({ kind: "filter", filter, widgets }))` and the analogous shape mapping.

    Use `??`/optional-chaining fallbacks everywhere so the function is TOTAL — an incomplete descriptor (both tableId and dynamicViewId undefined) resolves an empty activeList and contributes nothing, never throwing. Do NOT branch on `filter.operator`/`value`/`dataType` (Pitfall 5). Do NOT flatten `filters`/`dvFilters` into one list (Pitfall 1). Do NOT read `filterCombinationStore`.
