## Checklist detail

### 1. FSET — designer Settings toggle
- Toolbar "Settings" button opens the modal; segmented toggle Top bar ↔ Right panel.
- Switching flips the dashboard surface LIVE — no reload.
- Choice persists across a reload.
- A viewer WITHOUT `dashboards:edit` sees the designer's chosen mode AND no Settings button.

### 2. FPANEL — panel, chips, collapse
- Panel on the right; chips grouped table / dynamic-view / spatial.
- Remove a single chip; per-group "Clear all".
- Collapse → thin rail + count badge; collapse state persists on reload.
- Empty state at zero filters.

### 3. FSCOPE — applies-to + highlight
- Each filter shows "applies to N" + an expandable list (including layer names).
- Hover a filter → accent ring on exactly the affected widgets, no flicker on unaffected widgets/maps.
- Click → scroll to topmost + flash all; expanded-row click → scroll+flash that one.

### 4. FCLEAR — global clear-all
- "Clear all filters" appears only when filters are active.
- One action clears ALL tables + dynamic views + spatial draws.
- Every per-combination `_c{hash}` Kinetica view is DROPped by ref-count (check the network tab).

### 5. Filter scope on custom-panel charts
- On a Calendar Heatmap / Timeline / Numeric-Line widget: disabling one source in Filter Scope leaves the OTHER filters applied to that chart — verify on the live read path, not just config persistence.
- Those charts appear in the panel's "applies to N" count and highlight/scroll on hover/click.
- The legacy `respondToFilters` toggle is GONE from the config UI.
- A legacy calendar with `respondToFilters:false` still ignores filters (migrated to an empty allow-list).

### 6. Light + dark + narrow
- Panel / rail / chips / ring / flash / count badge / Settings toggle readable in BOTH themes.
- Narrow viewport (<900px) auto-collapses to the rail; expanding OVERLAYS (no reflow).
- **Added for `1061417`:** map basemap reads correctly in both themes — OSM plain in light, dark-filtered in dark; the BASEMAP group's per-theme CSS fields and Dark map / Light Gray Map / None presets apply live; no CARTO "API KEY REQUIRED" watermark on a default map.
- (Undefined classes + rgba/wrong tokens pass every automated gate but render broken — this is the check they cannot catch.)

### 7. Backward-compat
- A topbar/unset dashboard is byte-identical: top bar unchanged, grid layout intact.
- Switching a dashboard to panel and back is clean — no layout cascade/staircase (the `6c6eb3e` reflow fix + `breakpoint="lg"` pin hold).

### 8. Multi-map + info popup
- Multi-map info-popup scoping still holds (`activeWidgetId`, commit `9652182`).
- Panel-mode grid reflow still holds (commit `6c6eb3e`).
- **Added for `46b1300`:** with a filter active, click a map feature — the popup's record set must match the VISIBLE (filtered) tiles, not the whole table. Previously the popup queried the base table. Check both a table-bound layer and a dynamic-view-bound layer.
