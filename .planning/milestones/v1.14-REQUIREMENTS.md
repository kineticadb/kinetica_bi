# Requirements: Kinetica BI — v1.14 Class-Break & Chart Config Refinements

**Defined:** 2026-06-18
**Core Value:** Click-through data exploration — users drill into chart elements and the entire dashboard filters to that slice of data, enabling fast iterative analysis without writing SQL.

## v1.14 Requirements

Three independent frontend refinements. Each maps to roadmap phases.

### Numeric `<other>` Bucket (CBOTHER)

- [x] **CBOTHER-V114-01**: Operator can include an `<other>` catch-all bucket on a NUMERIC class-break config; it is emitted into the Kinetica WMS CB_VALS string as the literal `<other>` appended after the numeric ranges (e.g. `1:3,3:5,<other>`), mirroring the existing categorical support.
- [x] **CBOTHER-V114-02**: The `<other>` bucket toggle defaults ON for newly created or re-saved numeric class-break configs. An already-saved numeric layer with no stored flag is NOT silently changed — it renders exactly as today until the operator edits & re-saves it.
- [x] **CBOTHER-V114-03**: The numeric `<other>` row is presented in `CbConfigForm` consistently with the categorical `<other>` row (read-only value/chip, assignable per-break color/style) so the catch-all bucket gets its own color in the legend and on the map.

### Spatial-Mode SHAPE* Hiding (SHAPE)

- [x] **SHAPE-V114-01**: When spatial mode = `latlon` (points), the layer-level SHAPE* style fields (SHAPEFILLCOLOR, SHAPELINECOLOR, SHAPELINEWIDTH) are hidden in the raster config (`KineticaWmsLayerForm`) — point raster mode.
- [x] **SHAPE-V114-02**: When spatial mode = `latlon`, the per-break SHAPE* advanced fields (shapeFillColor, shapeLineColor, shapeLineWidth) are hidden in `CbConfigForm` — class-break (cb) raster mode.
- [x] **SHAPE-V114-03**: SHAPE* WMS params (SHAPEFILLCOLORS / SHAPELINECOLORS / SHAPELINEWIDTHS) are NOT emitted by `wmsUrlBuilder` when spatial mode = `latlon`, so SHAPE* values saved before this change (or on a layer switched to latlon) do not leak into the rendered point layer.

### Group-By for Timeline + Numeric-Line (GROUP)

- [x] **GROUP-V114-01**: Operator can set an optional group-by dimension column on the Timeline chart via a "Group By" picker in `TimelineConfigPanel`; clearing it returns to ungrouped behavior.
- [x] **GROUP-V114-02**: Operator can set an optional group-by dimension column on the Numeric-Line chart via a "Group By" picker in `NumericLineConfigPanel`; clearing it returns to ungrouped behavior.
- [x] **GROUP-V114-03**: When a group-by dimension is set, the chart is restricted to a SINGLE metric (each rendered series = one group value). Multi-metric (1–4) remains available only when no group-by is set; the UI enforces the mutual exclusion.
- [x] **GROUP-V114-04**: The Timeline / Numeric-Line SQL builders emit `GROUP BY <dimension>` alongside the existing time/x bin, and the renderers plot one color-coded series per group value with a sensible top-N group cap (defends against high-cardinality dimensions) — reusing the existing bar/line group-by pattern.

### Verification (VERIFY)

- [x] **VERIFY-V114-01**: All three v1.14 features are proven end-to-end via green automated gates (frontend vitest 100% from `packages/web`, web + server `tsc` clean, server vitest set-based ⊆ TD-V16-TEST-ISOLATION, theme-guard green) plus a blocking live operator walk-through covering all three features; the verification record is compiled and any UAT-surfaced gaps are fixed in-session and re-walked PASS. — Phase 73 PASSED (12/12 UAT items attested 2026-06-18).

## Out of Scope

Explicitly excluded for v1.14. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| `<other>` retroactively applied to already-saved numeric layers | Decision (2026-06-18): default-on for new/edited only — never silently change live dashboards |
| Metrics × groups (multi-metric AND group-by together) | Decision (2026-06-18): group-by collapses to a single metric — avoids series explosion + axis/color complexity |
| Custom per-threshold styling for the `<other>` bucket beyond a single color | Out of scope; `<other>` reuses the standard per-break color/style surface |
| Group-by for the calendar / map / other chart types | This milestone is timeline + numeric-line only |
| Server-side changes / new routes | FRONTEND-ONLY milestone; all features run through existing /api/sql + WMS params |
