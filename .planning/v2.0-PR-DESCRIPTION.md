**Title:** v2.0 AI-Driven Dashboards: AI widget, Generate, AI activity log, Claude Desktop connector

## Summary

A user asks a question in an AI widget on the dashboard, and the AI answers by changing the dashboard: it adds, edits, moves and removes charts and heatmap map layers, applies filters and builds session-only dynamic views. Every change is checked by the server against the shared contract and the live schema, can be reverted per answer, and is only saved when the user presses **Keep** (one all-or-nothing save with edit-rights and conflict checks). Designers can also generate a starter dashboard from a table, admins can browse an AI activity log, and Claude Desktop can build and edit dashboards through the same gateway (MCP connector).

AI is **off by default** (`AI_ENABLED=false`) and configured by env; MCP is off by default (`MCP_ENABLED=false`).
