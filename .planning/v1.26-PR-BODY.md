### v1.26 — Large Exports & Fixes

A user can export every row a records table shows. 1.5 million rows were verified live. The export runs as a server-side background job that streams to a private temp file, reports progress, cancels cleanly, resumes an interrupted download over HTTP Range and expires on schedule. Its rows are fixed at the moment the export starts.

**Requirements:** 21/21 (`EXPRT-V126-01..17`, `LINE-V126-01..04`) · **Phases:** 127–132, 41 plans · **Operator UAT:** live against real Kinetica (131: V1–V13 + Z1–Z5; 132: V1–V9)

- **The 1,000-row ceiling is removed** (127). `kineticaSql`'s hardcoded `limit: 1000` is now `KINETICA_MAX_ROWS_PER_QUERY` (default 20,000), split into `KINETICA_MAX_RECORDS_PER_CALL` batches. The in-browser CSV pages on `has_more_records`. Every caller is classified in `127-CALLER-AUDIT.md`. Truncation notices appear only when more rows really exist.
- **Export engine** (128). The runner pages with OFFSET over a job-private snapshot materialized view (`_kbi_exp_<id8>`) under a deterministic composite `ORDER BY`, and a `COUNT(*)` self-check confirms the row count. This design came out of a live spike: `paging_table` never created a table on this instance. Credentials are re-derived from the session on every batch, so an ended session fails the job closed. A CSV formula-injection guard covers both download paths.
- **Owner-only routes** (129). The routes live under `/api/exports`. A non-owner gets the same 404 on every `:id` route. Only complete, size-verified files are served (Range 206/416). **No new RBAC permission:** the existing dashboard-view gate is reused.
- **Lifecycle** (130). Covers a 24h TTL, a 5-min sweep that never deletes a file mid-download, and boot reconciliation (`server_restarted`, orphan cleanup). Env caps: `EXPORT_MAX_ROWS`, `EXPORT_MAX_FILE_MB`, `EXPORT_MAX_CONCURRENT_PER_USER`, `EXPORT_TTL_HOURS`.
- **UI** (131). An "Export records" dialog (name, Raw/Formatted, Compress (.zip), progress, cancel, ready toast) and an Exports page.
- **Line chart multi-series Group By** (132). Uses the bar chart's Group By builder: one line per series, every X label shown (tilt, then scroll), legend and Y title named after the metric, gaps for missing points, and the same drill as the bar chart.

### v1.25 — Schema Sync

An operator can check a registered table against live Kinetica from Datasets and read an impact report before deciding anything. The report names every widget, map layer, custom metric and column-format rule the change breaks; structured references are marked confirmed and free SQL *possibly* affected. Applying the refreshed snapshot is a separate choice and is recorded as per-table sync history. **The feature only detects and reports; it never rewrites a reference.** The flow is gated on `datasets:manage` AND `dashboards:manage_access`.

**Requirements:** 19/19 (`SSYNC-V125-*`) · **Phases:** 122–126, 21 plans · **Operator UAT:** 14/14 live

- Column fingerprinting keeps parameterised types. A rename is reported as one drop plus one add, never a guess.
- `columnRefs.ts` is a registry of 40 structured column-reference sites, built by a data-driven sweep that included nested `configPatch` JSON. It also covers 5 free-SQL sites, which are scanned heuristically.
- Apply replaces only `tables.columns` and `columns_fingerprint` in one transaction. A stale snapshot is refused with a 409. A `total_changes()` budget proves nothing else was written.

### Reviewer notes

1. **New dependency:** `d3-format` on the server, so that Formatted export values match the client byte for byte. It was already a web dependency and has a parity spec. The .zip writer (streaming ZIP64) is in-repo and adds no dependency.
2. **Compression is .zip, not .gz.** The operator's macOS Archive Utility refuses every `.gz`. An earlier wrong fix (`0418602`) was reverted in `c83d138`.
3. **CSS and layout defects passed every automated gate** (a trapped dialog, oversized text, focus lost under StrictMode, a clipped Y axis). The operator checkpoint caught all of them, as it has for three milestones running. jsdom applies no CSS.
4. **New env vars:** `KINETICA_MAX_ROWS_PER_QUERY`, `KINETICA_MAX_RECORDS_PER_CALL`, `CSV_INBROWSER_MAX_ROWS`, `EXPORT_*`. `EXPORT_DIR` and `EXPORT_VIEW_TTL_MINUTES` are not yet in `.env.example`.

### Known gaps (carried to backlog, not blockers)

- Proxy-path resume (`curl -C -` through deploy nginx `:8080`) has not been exercised. All resume checks ran against `:4000`.

- A killed or session-ended job leaves its `_kbi_exp_*` snapshot until the TTL expires.
