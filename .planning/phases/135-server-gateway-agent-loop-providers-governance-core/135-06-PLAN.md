<objective>
Build the one validation gateway every AI change passes, plus the shadow state it checks references against and the live-schema port it probes as the user.

**D-16 OVERRIDES the research's "RBAC per op kind" table.** The gateway does NOT check `dashboards:edit` / `widgets:configure` / `layers:manage` / `dynamic_views:manage`: session-only structural ops are allowed for any `ai:use` user. The permission stage is exactly: `ai:use` (re-read) + `canViewDashboard` (re-read). Table/column access is enforced by the live-schema stage (the user-credentialed probe). Edit rights are Keep's job (Phase 141) — do NOT create `opPermissions.ts` here.

Purpose: AISAFE-V20-02 (one gateway; failing change rejected) and AISAFE-V20-03 (never exceeds the user's rights). The loop (135-09) only emits ops that returned `{ok:true}`.
