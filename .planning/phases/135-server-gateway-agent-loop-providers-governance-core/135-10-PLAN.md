<objective>
Expose the AI core over HTTP: `POST /api/ai/ask` (SSE over POST, the S2-proven pattern) and `GET /api/ai/config`, wiring permission → config → body → dashboard access → in-flight → caps/audit admit → stream → loop → single `result` → finalize audit.

Purpose: AIGOV-V20-01 server refusal; AISAFE-V20-02/03 end to end (only gateway-approved ops reach the browser); AIGOV-V20-04 (one audit row per answer); AIGOV-V20-06 (cap refusals with why/when).

SSE event contract (137 builds against it; JSON in `data:`): `status {phase, label, seconds?}`, `step {n, tool, label}`, `result {answerId, text, ops, skipped:[{label, stage, reasons}]}` (ONLY on outcome ok), `error {code, message}`, `done {answerId, outcome, steps, usage}`. Error codes: `AI_CAPPED`, `AI_RATE_LIMITED`, `AI_PROVIDER_ERROR`, `AI_CANCELLED`, `AI_SESSION_ENDED`, `AI_INTERNAL`.
