**Removed calendar/timeline/numericline from NON_TRIGGER_TYPES in both the combination-orchestrator and reverse-map, and added a key-presence-discriminated coalesce helper so legacy calendar `respondToFilters:false` configs migrate cleanly to an empty-allowlist scope.**

## Accomplishments
- New pure `coalesceCalendarFilterSelection` helper resolves a calendar widget's effective `FilterSelectionConfig`, correctly distinguishing "legacy respondToFilters:false" (→ respond to none) from "no respondToFilters key at all" (→ accept-all) via key-presence, not value.
- `NON_TRIGGER_TYPES` no longer lists `"timeline"`, `"numericline"`, `"calendar"` in either `useCombinationOrchestrator.ts` or `useReverseFilterMap.ts` — both edited atomically in the same commit.
- Orchestrator's table loop and dv loop (dvScopeDisabled short-circuit preserved first) both thread the calendar coalesce before resolving the filter set.
- Reverse-map's `enumerateVizDescriptors` threads the same coalesce so the panel's applies-to count/highlight agree with what the orchestrator actually binds.
- `FILTER_PRODUCING_TYPES` (the orthogonal filter-SOURCE set) confirmed untouched via `git diff --stat`.
