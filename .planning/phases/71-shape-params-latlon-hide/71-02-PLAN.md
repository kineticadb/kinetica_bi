<objective>
Suppress SHAPE* WMS param emission (SHAPEFILLCOLORS / SHAPELINECOLORS / SHAPELINEWIDTHS) in `wmsUrlBuilder.ts` whenever `config.spatialMode === "latlon"`, in BOTH the raster branch and the classbreak branch. This is the leak-prevention requirement: a layer with stale saved shape values (saved before this change, or carried over after switching the layer to latlon) MUST NOT emit those params for a point layer. Hiding the UI fields (Plan 01) does NOT clear saved values — the builder gate is what actually prevents the leak.

Purpose: SHAPE-V114-03. Mirrors the v1.9 Phase 53 emission-suppression precedent. Saved config values are NOT deleted — switching back to wkt/wkb restores emission from the still-present values.

Output: One library edit (two gated branches) + regression tests covering raster AND classbreak leak prevention, plus the wkt/wkb no-regression assertions.
</objective>
