# Phase 93.5 Plan 01: Spatial Hash Extension + Resolver Summary

**One-liner:** WKT-sorted optional `shapes?` 4th param added to `stableComboHash` plus new `resolveSpatialShapes` all-or-nothing resolver — both pure, zero-dep, frontend-only foundations for spatial filter combination model.

## Final stableComboHash Signature

```typescript
export function stableComboHash(
  sourceType: "table" | "dv",
  sourceId: number,
  filters: ActiveFilter[],
  shapes?: Pick<Shape, "wkt">[],   // NEW — optional; backward-compatible
): string
```

**Spatial segment format (`;s:` delimiter):**
- Column segments: `col|op|"val";col2|op2|"val2"` (unchanged from Phase 88)
- Spatial segments appended: `;s:WKT_1;s:WKT_2` (shapes sorted by wkt ascending)
- Spatial-only (no columns): `s:WKT_1;s:WKT_2`
- NOFILTER sentinel: fires only when BOTH column and spatial segments are empty

**Examples:**
- `stableComboHash("table", 5, [])` → `"table:5:NOFILTER"` (unchanged)
- `stableComboHash("table", 5, [], [])` → `"table:5:NOFILTER"` (byte-identical)
- `stableComboHash("table", 5, [], [{wkt:"POLYGON_X"}])` → `"table:5:s:POLYGON_X"`
- `stableComboHash("table", 1, [fA], [{wkt:"BBB"},{wkt:"AAA"}])` → same as `[{wkt:"AAA"},{wkt:"BBB"}]` (order-independent)

## resolveSpatialShapes Contract

```typescript
export function resolveSpatialShapes(
  cfg: FilterSelectionConfig | undefined,
  allShapes: Shape[],
): Shape[]
```

| cfg | result |
|-----|--------|
| `undefined` | `allShapes.slice()` (all shapes) |
| `{ sourceMode: "all", ... }` | `allShapes.slice()` (all shapes) |
| `{ sourceMode: "allowlist", allowedSourceWidgetIds: [SPATIAL_DRAWS_SENTINEL, ...] }` | `allShapes.slice()` (all shapes) |
| `{ sourceMode: "allowlist", allowedSourceWidgetIds: [42] }` | `[]` (sentinel absent) |
| `{ sourceMode: "allowlist", allowedSourceWidgetIds: [] }` | `[]` (empty list) |
| any cfg, `allShapes = []` | `[]` (empty passthrough) |
