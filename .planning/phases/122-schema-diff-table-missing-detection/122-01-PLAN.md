<objective>
Build the pure fingerprint parser that turns a real Kinetica `/show/table` body into a
per-column type fingerprint precise enough that BOTH `int -> double` AND
`varchar(8) -> varchar(32)` are detectable, and extend `kineticaShowTable` so a caller can
ask for `no_error_if_not_exists: "true"` — the signal that makes "table missing" structurally
distinguishable from "could not reach Kinetica".

Purpose: this is the evidence-handling layer of the whole milestone. The spike
(`122-SPIKE-NOTES.md`) proved that neither `type_schemas` nor `properties` alone is sufficient,
and that `INFORMATION_SCHEMA.DATA_TYPE` is actively wrong about char width. Everything Phases
124 and 125 read is built on the shape this plan defines.

Output: `packages/server/src/lib/schemaFingerprint.ts` (pure, zero DB, zero network) plus a
one-field extension to `kineticaShowTable`.
</objective>

Export exactly:

```ts
export type ColumnFingerprint = {
  /** Avro base type from type_schemas, with "null" stripped from unions. e.g. "int" | "long" | "float" | "double" | "string" | "bytes" | "boolean" */
  base: string;
  /** Type-refining /show/table property markers, lowercased and sorted. e.g. ["char4"], ["int8"], ["timestamp"] */
  refinements: string[];
};
export type ColumnFingerprintMap = Record<string, ColumnFingerprint>;
export type FingerprintSnapshot = { v: 1; columns: ColumnFingerprintMap };
export type TablePresence = "present" | "missing" | "unreadable";
```

`NON_TYPE_PROPERTIES` — the EXCLUSION set. Everything not in it is treated as type-refining
(fail toward reporting a change, never toward silence):

```ts
export const NON_TYPE_PROPERTIES: ReadonlySet<string> = new Set([
  "data", "store_only", "disk_optimized", "text_search",
  "primary_key", "shard_key", "dict", "init_with_now",
  "nullable", "unique",
]);
```
Comment `"nullable"` explicitly: it is excluded because nullability detection is SSYNC-F5,
DEFERRED — including it here would silently ship F5 as a retype.

`tablePresence(body: unknown): TablePresence`
- body is not a non-null object -> `"unreadable"`
- `body.table_names` is not an array -> `"unreadable"`
- `table_names.length === 0` -> `"missing"`
- else -> `"present"`
Header comment: a malformed body must NEVER read as "your table was deleted" — that is the
whole point of the three-state return.

`parseColumnFingerprints(body: unknown, tableName: string): ColumnFingerprintMap`
- Returns `{}` on any malformed input. Never throws.
- Pick the index: if `body.table_names` is an array, use `findIndex(n => n === tableName)`;
  fall back to 0 when not found. Same rule as `parseTemporalColumns`.
- Base types: read `body.type_schemas[idx]`. It may be a JSON STRING (Kinetica's documented
  `TypeSchemas []string`) or an already-parsed object — accept both: if `typeof === "string"`,
  `JSON.parse` inside a try/catch that returns `{}` on failure. Read `.fields`, an array of
  `{ name, type }`. For each field, normalize the Avro type:
  - `typeof type === "string"` -> use it
  - `Array.isArray(type)` -> filter out `"null"`, take the first remaining entry; if it is a
    string use it, otherwise `"unknown"`
  - object with a string `.type` -> use `.type`
  - anything else -> `"unknown"`
  Lowercase the result.
- Refinements: read `body.properties[idx]`, a name-keyed map to string arrays. For column `c`,
  take its list, `String(p).toLowerCase()` each entry, drop any in `NON_TYPE_PROPERTIES`,
  de-duplicate, and `.sort()`. A column absent from `properties` gets `[]`.
- Emit one entry per field in `type_schemas.fields` (that is the authoritative column list).
  A key present only in `properties` is ignored — `properties` has no base type to pair with.

`formatFingerprint(fp: ColumnFingerprint): string`
- `refinements.length === 0` -> `fp.base`
- else -> `` `${fp.base}(${fp.refinements.join(",")})` `` — e.g. `string(char4)`, `int(int8)`,
  `long(timestamp)`, `float`.

`parseFingerprintSnapshot(raw: string | null | undefined): ColumnFingerprintMap | null`
- null / undefined / empty-or-whitespace string -> `null`
- JSON.parse inside try/catch; on throw -> `null`
- parsed value is not an object, or `parsed.v !== 1`, or `parsed.columns` is not an object -> `null`
- otherwise return `parsed.columns` after coercing each entry to a well-formed
  `{ base: string, refinements: string[] }` (skip entries that are not objects, coerce a missing
  `refinements` to `[]`).
- `null` means "no usable precise baseline" — the caller turns that into `baseline_required`.
  Document that: an old-format row (NULL column) and a corrupt snapshot both land here, and
  neither is an error.

`serializeFingerprintSnapshot(columns: ColumnFingerprintMap): string`
- `JSON.stringify({ v: 1, columns })`. Provided for Phase 125's apply — Phase 122 never calls it
  outside tests. Say so in a comment.
