## Decisions Made

- New standalone module (`calendarBuckets.ts`) rather than expanding `calendarBin.ts` — keeps separation clean; Plan 03's gapFill import is unambiguous
- `fmtUTC` uses `getUTC*` getters, not `toISOString()`, to emit space-separator format matching the SQL DATE_TRUNC output (`"YYYY-MM-DD HH:mm:ss"`); keys must string-equal SQL row keys in Plan 03's per-group lookup
- Month last-day computed via `Date.UTC(y, mo+1, 0).getUTCDate()` — the day-0 trick handles all month lengths + leap Feb without a lookup table
- Week enumeration walks from the Monday on-or-before range-start, includes only week-starts whose UTC month/year falls in the group — "start falls in range" rule from CONTEXT decision (2)
