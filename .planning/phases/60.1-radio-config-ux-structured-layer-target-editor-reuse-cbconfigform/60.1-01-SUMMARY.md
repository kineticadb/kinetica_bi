## What Was Built

### `validateLayerSnapshot` (actionAllowList.ts)

A denylist validator for the designer-UI layer-appearance snapshot path (Phase 60.1 RE-SCOPE). Rejects any key in `PERMANENTLY_BLOCKED_KEYS ∪ DATA_BINDING_KEYS`; accepts all other render/style/info-popup keys. Uses `Object.keys()` enumeration — never spreads the untrusted patch (proto-pollution boundary).

`DATA_BINDING_KEYS` blocks: `table_id`, `tableId`, `tableRef`, `dynamic_view_id`, `dynamicViewId`, `spatialMode`, `latColumn`, `lonColumn`, `wktColumn`, `wkbColumn`, `trackXColumn`, `trackYColumn`, `trackIdColumn`, `trackOrderColumn`.

### `snapshotToLayerForm` (radioGroupLayerPatch.ts)

Converts a flat layer-appearance snapshot into the inputs `KineticaWmsLayerForm` needs:
- `config`: one blob with renderMode + ALL style keys + `cb_config` + `track_config` (lifted into the blob — same key names, mirrors LayersModal.tsx 557-574); data-binding/meta keys stripped defensively; `info_*` removed.
- `info`: `{ info_enabled?, info_columns?, info_template? }` — surfaced separately for the form's `infoEnabled`/`infoColumns`/`infoTemplate` props.

### `layerFormToSnapshot` (radioGroupLayerPatch.ts)

Converts a form config blob (+ separate infoPatch) back to a flat snapshot. Strips `STRIP = DATA_BINDING_KEYS ∪ PERMANENTLY_BLOCKED_KEYS ∪ INFO_FIELDS`. `cb_config`/`track_config` remain top-level siblings of `renderMode` (Plan 02's engine produces the DTO-shaped `{ config: {...}, cb_config, ... }` overlay at apply time). `info_*` fold to flat top-level. Output always passes `validateLayerSnapshot`.

### Back-compat

`LAYER_FORM_PATCH_FIELDS`, `patchToLayerFormConfig`, `layerFormConfigToPatch` retained unchanged (first-cut flat-4-field adapter still referenced by Advanced JSON fallback and any first-cut options).
