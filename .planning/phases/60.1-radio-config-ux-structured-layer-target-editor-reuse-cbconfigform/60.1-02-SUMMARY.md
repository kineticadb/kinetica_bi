## What Was Built

### `splitLayerSnapshot` (applyWidgetAction.ts)

Local helper function replacing `splitLayerPatch` in the layer dispatch branch. `LAYER_SNAPSHOT_TOP_LEVEL = ["cb_config","track_config","info_enabled","info_columns","info_template"]` governs the split: these 5 fields stay top-level in the DTO-shaped overlay; everything else (renderMode, colormap, BLUR_RADIUS, POINTCOLOR, any style key) goes nested under `config`. This matches `effectiveLayers` deep-merge semantics exactly — no engine-merge change required.

### Layer dispatch via denylist (`applyWidgetAction.ts`)

Step 2 validation now branches on `target.kind`:
- `"layer"` → `validateLayerSnapshot(configPatch)` (denylist: accept render/style/info; reject data-binding/spatial/meta)
- `"widget"` / `"dynamicView"` → `validateActionPatch(...)` (strict allow-list, unchanged)

Step 3 overlay build uses `splitLayerSnapshot` for layer targets (replaces `splitLayerPatch`). Widget/dv paths untouched. `splitLayerPatch` import removed (no longer used). `validateActionPatch` import kept (widget/dv dispatch).

### Save-time validity via denylist (`radioGroupConfig.ts`)

`validateRadioOption` branches on `option.action.target.kind === "layer"`:
- layer → `validateLayerSnapshot(option.action.configPatch)`
- widget/dv → `validateActionPatch(...)` (unchanged)

The empty-configPatch rule (Rule 1) runs before the branch — unchanged.

### Live-read test (`MapChartRenderer.spec.tsx`)

New describe block `"60.1 — overlaid info_enabled:0 drops layer from eligibleLayers (read-live)"`. Test flow:
1. Mount renderer with one baseline `info_enabled=1` latlon layer.
2. Trigger singleclick → layer IS queried (eligible baseline).
3. Drive overlay via REAL `widgetActionStore.setControlContribution(999, { layer: { 1: { info_enabled: 0 } } })` — DTO-shaped top-level (not nested in config).
4. Trigger singleclick again → layer is NOT queried. `effectiveLayers` spread the top-level `info_enabled:0` onto the merged layer; `eligibleLayers` filtered it out live without remount. GAP-61 read-once-at-mount risk closed for the snapshot path.
