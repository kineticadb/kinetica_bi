Build `CalendarRenderer.tsx` — the read-only SVG calendar heatmap. It owns its full data
lifecycle (mirrors TimelineRenderer) and renders a gap-filled domain/subdomain grid with a
reactive color scale, legend, both-axis labels, and per-cell tooltips.

Two tasks:
1. Fetch lifecycle: resolve the FROM target via the full precedence (fvViewName ||
   dvFilterViewName || dvViewName || "schema.table") BEFORE building SQL (NO fromSwap),
   issue a SINGLE runSql(buildCalendarSql(...)), decode rows, manage loading/error/empty,
   and re-fetch on the filter-aware dep set (CAL-V113-05). The dv path is assembled from
   WidgetRenderer.tsx §425-446 (Timeline lacks it).
2. SVG render: 2D gap-fill (useMemo), reactive color domain (useMemo over data), 5-bucket
   quantized cells, theme-grey empties (non-interactive, no tooltip), discrete Less→More
   legend, both-axis labels (smart-by-unit sparse subdomain labels), per-cell tooltip.

Purpose: CAL-V113-04 (grid + colors + gap-fill + labels + tooltip, theme tokens only) and the
CAL-V113-05 filter-aware-consumer re-fetch.
