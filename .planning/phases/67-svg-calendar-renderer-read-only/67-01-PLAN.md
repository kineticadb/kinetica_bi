<objective>
Build the three PURE, unit-testable foundations the SVG CalendarRenderer (Plan 67-02) composes:
1. A reactive color scale: `computeDomain(data)` → `[min,max]`, and `quantizeToBucket(value, domain, count)` → bucket index 0..count-1 over a LINEAR domain split into N equal bands. Plus `calendarBucketColors(theme)` → 5 discrete CSS color strings via `themeColorsFor(getCbColorTheme(theme), 5)`.
2. A 2D gap-fill: given the populated `{domain_bucket, subdomain_bucket, value}` rows from `buildCalendarSql`, compute the FULL expected `domain_bucket × subdomain_bucket` grid and fill missing positions with `null` (grey) — never collapse neighbors.
3. Extend `useChartAxisColors()` with a theme-aware `emptyCell` concrete color so the renderer can fill grey cells WITHOUT putting a raw hex (or an SVG-incompatible CSS var) in `CalendarRenderer.tsx`.

Purpose: TDD-isolate the two genuinely-new algorithms (5-bucket quantize + 2D gap-fill) — Timeline's gap-fill is only 1D — so the renderer plan stays a pure composition/wiring exercise. Mirrors how Phase 66 isolated `estimateCalendarCells`.
Output: Two pure lib modules + specs (RED→GREEN), plus a one-field extension to `chartColors.ts`.
