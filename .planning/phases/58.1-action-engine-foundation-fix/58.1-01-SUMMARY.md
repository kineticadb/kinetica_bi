## Effective Layer Merge (before → after)

**Before (Phase 58 flat spread — WRONG):**
```typescript
// In MapChartRenderer.tsx:
allLayers.map((l) => layerOverrides[l.id] ? { ...l, ...layerOverrides[l.id] } : l)
// Flat spread — config.renderMode could NEVER change; overlay would add renderMode
// as a top-level layer key (not in config blob) — render pipeline reads config.renderMode.
```

**After (Phase 58.1 deep-merge — CORRECT):**
```typescript
allLayers.map((l) => {
  const ov = layerOverrides[l.id];
  if (!ov) return l;
  const { config: cfgPatch, ...topLevel } = ov as { config?: Record<string, unknown>; [key: string]: unknown };
  return cfgPatch
    ? { ...l, ...topLevel, config: { ...(l.config as Record<string, unknown>), ...cfgPatch } }
    : { ...l, ...topLevel };
})
```
