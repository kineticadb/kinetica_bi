ROOT CAUSE: Async callbacks (XHR onreadystatechange; OL source 'imageloaderror'/'imageloadend')
hold strong references to the (now-detached) OL image, source, and react setState functions.
React unmount detaches the DOM but cannot abort the in-flight XHR or remove the OL listeners.

THE FIX — mountedRef cleanup-gate pattern (mirrors v1.3 Phase 15's materializeAbortRef pattern; see STATE.md "Phase 15 LIFE-V13-04" decision). Add a single `mountedRef` and guard every async callback with it.

      const xhr = new XMLHttpRequest();
      xhr.open("GET", src, true);

      xhr.responseType = "arraybuffer";

  [],
