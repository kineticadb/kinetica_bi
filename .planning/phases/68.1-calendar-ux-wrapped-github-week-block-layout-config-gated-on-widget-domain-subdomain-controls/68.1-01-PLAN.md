<objective>
Create a PURE, fully-unit-tested layout helper that maps the gap-filled calendar grid
(`gapFillCalendar` output) into date-derived 2D blocks per domain group — the hardest part of
CALUX-V113-01 (wrapped GitHub week-block layout), isolated exactly the way Phases 66-01 / 67-01
isolated `estimateCalendarCells` / `calendarColorScale` as pure modules.

Purpose: The Phase 67 renderer currently positions cells by FLAT index (`ci * step`, `ri * step` —
CalendarRenderer.tsx §466-469), producing one tall column. This helper computes (col,row) from each
cell's DATE (`subdomainKey`), so the renderer (Plan 03) just consumes positioned blocks. Pure +
testable isolates the date→day-of-week / week-index / grid math from React.

Output: `packages/web/src/lib/calendarLayout.ts` (zero React/Zustand imports) + its spec.
</objective>
