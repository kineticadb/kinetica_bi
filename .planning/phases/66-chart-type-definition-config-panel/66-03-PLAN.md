<objective>
Build `CalendarConfigPanel` — the dv-aware custom config panel for the calendar chart type (CAL-V113-02 + CAL-V113-05 cap portion). It is a near-clone of `TimelineConfigPanel` with four divergences: (1) its data-source dropdown lists Dynamic Views (not base-table-only) and dual-writes the dv binding, (2) a SINGLE metric+aggregation instead of the N-row builder, (3) dependent Domain/Subdomain dropdowns enforcing the 8 valid combos, (4) a save-time cell-count cap that hard-blocks runaway grids.

Purpose: This is the operator-facing surface of Phase 66. After this, an operator can configure a calendar end-to-end and only a VALID, bounded config can save. The renderer is Phase 67 — this panel persists config only.
Output: `CalendarConfigPanel.tsx` + `CalendarConfigPanel.spec.tsx`. NO renderer, NO registry wiring (that is Plan 66-04).
