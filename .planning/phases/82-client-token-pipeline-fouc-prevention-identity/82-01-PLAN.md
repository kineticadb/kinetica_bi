<objective>
Build the foundation of the client brand pipeline: a `brandStore` (zustand, mirroring `theme.ts`) that fetches `GET /api/branding` at startup, applies token overrides to `:root` via inline `setProperty`/`removeProperty`, caches the payload to `localStorage("kbi-brand-tokens")` (the exact shape that Plan 82-02's inline FOUC script will read), sets `document.title`, re-applies on dark/light toggle, and propagates cross-tab changes via `BroadcastChannel("kbi-brand-updated")` + a `window.focus` refetch fallback. Also adds the unauthenticated `fetchBranding()` client fn and the `BrandStyleInjector` (custom CSS via `textContent`).

Purpose: BRANDFND-03 — the client applies the active brand at runtime via CSS custom properties and picks up admin changes in other tabs without a hard refresh. This plan is the FOUNDATION; 82-02 (FOUC) depends on the localStorage shape this writes, and 82-03 (identity) depends on this store existing.
Output: `brandStore.ts` + spec, `fetchBranding()` in `client.ts`, `BrandStyleInjector.tsx` + spec, App.tsx wiring.
</objective>
