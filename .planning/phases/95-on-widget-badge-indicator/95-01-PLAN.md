<objective>
Add an on-widget "N of M filters" badge to each single-scope CHART widget's header that ignores at least one active filter, with a hover breakdown of applied vs ignored filters (reason: "source excluded").

Purpose: Give designers/analysts immediate, glanceable feedback on which active filters a widget is applying without opening its config panel (COMM-V118-01).
Output: A pure summary helper + thin hook, a header badge component, one new global.css class, and the integration into the dashboard widget header. FRONTEND-ONLY.

Scope locks (from phase decisions):
- Single-scope CHART widgets only (bar, line, pie, scatter, aggregated table, timeline, numericline, calendar). The MAP widget + per-layer badges are DEFERRED (COMM-V2-02) — never badge maps/layers here.
- Badge renders ONLY when appliedCount < totalCount (≥1 ignored). Accept-all / nothing-ignored → NO badge → byte-identical to v1.17 visuals (SC1).
- Badge data is computed LOCALLY (pure), NOT read from the combination store. REUSE resolveFilterSet (Phase 88) + resolveSpatialShapes (Phase 93.5) — do NOT reimplement resolve logic.
- The global top filter-bar is UNCHANGED.
</objective>
