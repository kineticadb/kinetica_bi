## Scope boundary — READ FIRST

Phase 111 delivers **save and clear only**. Phase 112 is what makes a map
actually OPEN at its saved view.

So: after saving a default, reopening the dashboard will still show the map at
the world view. **That is not a bug in this phase** — do not report it here. What
Phase 111 must get right is that the value is captured correctly, displayed
honestly, persisted in the widget config, and clearable.

Automated verification already passed 7/7 must-haves. These tests cover only
what no test in this repo can establish: whether it reads correctly and behaves
sanely in a real browser.
