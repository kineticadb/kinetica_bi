Phase 55 server API contract (55-02-SUMMARY.md — the API this UI consumes):
- GET    /api/dashboards/:id/access  → 200 { grants: [...] }            (gated by dashboards:manage_access → 403 otherwise)
- POST   /api/dashboards/:id/access  → 201 { grants: [...] }            body { grantee_type, grantee }
- DELETE /api/dashboards/:id/access  → 200 { grants: [...] }            body { grantee_type, grantee }   (DELETE READS BODY, not query)
- 400 on bad input.
Grant row shape (each element of `grants`):
  { grantee_type: "user" | "role", grantee: string, created_at: string }   // created_at is ISO; user grantees are lowercased server-side

         const response = await apiFetch(`${API_BASE}/api/dashboards/${dashboardId}/access`, {

         input: { grantee_type: "user" | "role"; grantee: string },

           method: "DELETE", headers: { "Content-Type": "application/json" }, body: JSON.stringify(input),

         const json = await response.json();
         return json.grants as DashboardGrantDto[];
       };
