    computeCellBounds implementation rules (lock in a module comment citing PITFALLS Pitfall 1 + 2):
    - Parse dateIso into a UTC ms epoch (new Date(dateIso).getTime() — ISO with Z is UTC-safe).
    - Truncate to the subdomain unit using getUTC* / Date.UTC:

        day   → Date.UTC(y, mo, d, 0,0,0,0)
        week  → day-truncate, then back up to the documented week-start (Monday/ISO):

        month → Date.UTC(y, mo, 1, 0,0,0,0)

        week: +7×86_400_000ms; month: Date.UTC(y, mo+1, 1) so Dec rolls to next Jan correctly).
      DO NOT add fixed ms for month (months vary 28-31 days) — use the Date.UTC(y, mo+1, 1) rollover.
    - cellEnd = new Date(nextBucketStart − 1).toISOString(); cellStart = new Date(start).toISOString().

    NOTE: `subdomainUnit` here is the per-cell unit. computeCellBounds only needs the subdomain (the
    cell granularity) — the domain does not affect a single cell's bounds.
